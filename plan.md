# План розробки Telegram-бота "Nova Poshta AI Waybill Generator"

## Опис проекту
Створення Telegram-бота на Python (aiogram 3.x), який за допомогою штучного інтелекту (з гнучким вибором OpenAI-сумісного API, офіційного OpenAI або Gemini) парсить неструктурований текст із реквізитами отримувача (ПІБ, телефон, місто, номер відділення/поштомату, опис, оціночна вартість) з підтримкою редагування створених чернеток живою мовою, висвітленням активних посилок та нижньою клавіатурою з кнопками.

## Основні компоненти (Виконано у v0.6.0)
1. [x] **AI Entity Extractor & Context Memory (`src/ai/`)**:
   - Підтримка контекстного збереження та об'єднання даних отримувача з доповненнями (наприклад, редагування опису чи оцінки живою мовою).
   - Повна сумісність з `gpt-5.6-luna`, `gpt-4o-mini`, `o1`, `gemini-3.6-flash`.

2. [x] **Nova Poshta API Client (`src/nova_poshta/`)**:
   - Виправлено імпорт `WaybillItemInfo`.
   - Створення контрагента та створення ТТН (`InternetDocument/save`).
   - Оновлення чернеток ТТН (`InternetDocument/update`).
   - Видалення ТТН/чернеток (`InternetDocument/delete`).
   - Отримання активних посилок (`InternetDocument/getDocumentList`).

3. [x] **Telegram Bot Interface (`src/bot/`)**:
   - Постійна клавіатура бота Reply Keyboard меню в 1 клік (`📦 Активні посилки`, `📝 Мої чернетки (ТТН)`, `⚙️ Налаштування`, `❓ Допомога`).
   - Додано кнопку `✏️ Редагувати ТТН` до карток чернеток з оновленням накладної живим текстом та кнопками.
   - Повна українізація всіх текстів, карток та кнопок.

4. [x] **Персональне збереження даних (`src/storage.py`)**:
   - Локальний менеджер збереження налаштувань користувача та створених чернеток.
