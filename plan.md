# План розробки Telegram-бота "Nova Poshta AI Waybill Generator"

## Опис проекту
Створення Telegram-бота на Python (aiogram 3.x), який за допомогою штучного інтелекту (з гнучким вибором OpenAI-сумісного API, офіційного OpenAI або Gemini) парсить неструктурований текст із реквізитами отримувача (ПІБ, телефон, місто, номер відділення/поштомату, опис, оціночна вартість) без використання регулярних виразів, з підтримкою розрізнення міст-дублікатів, збереження розпізнаних об'єктів міста й відділення під час оновлення конкретних полів (опис, оцінка, ПІБ, телефон), об'єднання перепощених повідомлень, редагування чернеток живою мовою, автоматичним скиданням контексту та нижньою клавіатурою з кнопками.

## Основні компоненти (Виконано у v0.11.0)
1. [x] **AI Entity Extractor & Multi-Part Memory (`src/ai/`)**:
   - 100% AI-ориєнтований парсинг без регулярних виразів.
   - Повна сумісність з `gpt-5.6-luna`, `gpt-4o-mini`, `o1`, `gemini-3.6-flash`.

2. [x] **Nova Poshta API Client (`src/nova_poshta/`)**:
   - Кросс-перевірка відділень/поштоматів з виключенням зайвих повторних API запитів при редагуванні окремих полів (опис, вартість тощо).
   - Створення контрагента та створення ТТН (`InternetDocument/save`).
   - Оновлення чернеток ТТН (`InternetDocument/update`).
   - Видалення ТТН/чернеток (`InternetDocument/delete`).
   - Отримання активних посилок (`InternetDocument/getDocumentList`).

3. [x] **Telegram Bot Interface (`src/bot/`)**:
   - Миттєве оновлення конкретних полів (опис, вартість, телефон) без повторного пошуку відділення у базі НП.
   - Інтерактивна кнопкова вибірка населеного пункту (`CitySelectCallback`).
   - Асинхронний дибаунсер (`USER_MESSAGE_BUFFERS`, `USER_DEBOUNCE_TASKS`).
   - Кнопка `✏️ Редагувати ТТН` та скидання контексту сесії.

4. [x] **Персональне збереження даних (`src/storage.py`)**:
   - Локальний менеджер збереження налаштувань користувача та створених чернеток.
