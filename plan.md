# План розробки Telegram-бота "Nova Poshta AI Waybill Generator"

## Опис проекту
Створення Telegram-бота на Python (aiogram 3.x), який за допомогою штучного інтелекту (OpenAI-сумісного API / Gemini) парсить неструктурований текст із реквізитами отримувача без регулярних виразів, формує експрес-накладні (ТТН як у відділення/поштомати, так і на адресну доставку кур'єром), забезпечує інтелектуальне об'єднання чернеток у реєстри (ScanSheet) на основі природномовних запитів та генерує штрих-коди Code128 для швидкого сканування на відділеннях Нової Пошти.

## Основні компоненти (Виконано у v0.19.6)
1. [x] **AI Entity Extractor & Smart Contextual Editing (`src/ai/`)**:
   - Повна ізоляція AI-провайдера за Telegram `user_id`.
   - Повноцінне природномовне редагування будь-якої частини накладної (ПІБ, телефон, місто, вулиця/будинок, відділення/поштомат, опис, оцінка, наложка).
   - Розпізнавання суми та виплати накладеного платежу (`cod_amount`, `cod_payment_type`).
   - Метод `filter_drafts_for_register` — прийом масиву активних чернеток у форматі JSON разом із промптом користувача.

2. [x] **Nova Poshta API Client, Address Delivery & Barcode Generator (`src/nova_poshta/`, `src/utils/`)**:
   - Пряме завантаження чернеток з кабінету НП через `InternetDocument/getInternetDocumentList`.
   - Інтелектуальний пошук вулиць через `Address/getStreet` з перестановками слів та ранжуванням результатів.
   - Реєстрація адрес отримувача через `Address/save`.
   - Створення накладних адресної доставки (`ServiceType: "WarehouseDoors"`).
   - Генерація високоякісного Code128 штрихкоду реєстру (у форматі `105-79184007`).

3. [x] **Telegram Bot Interface & Keyboards (`src/bot/`)**:
   - Інтерактивна клавіатура вибору вулиці/провулку (`StreetSelectCallback`) при знаходженні декількох варіантів.
   - Компактна схема `WaybillActionCallback` (action, session_id), що унеможливлює ліміт 64 байти в Telegram.
   - Збереження контексту `USER_LAST_PARSED_INFO` для редагування накладної голосом або текстом.

4. [x] **Персональне збереження даних (`src/storage.py`)**:
   - Індивідуальне збереження налаштувань користувача в `data/user_settings.json` за Telegram `user_id`.
   - Автоматичне очищення відправлених чернеток (`purge_sent_drafts`) та застарілих/відправлених реєстрів (`purge_old_or_sent_scansheets`).
