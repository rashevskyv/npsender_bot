# План розробки Telegram-бота "Nova Poshta AI Waybill Generator"

## Опис проекту
Створення Telegram-бота на Python (aiogram 3.x), який за допомогою штучного інтелекту (з гнучким вибором OpenAI-сумісного API, офіційного OpenAI або Gemini) парсить неструктурований текст із реквізитами отримувача (ПІБ, телефон, місто, номер відділення/поштомату, опис, оціночна вартість) з підтримкою контекстного редагування активних посилок, керування чернетками та нижньою клавіатурою з кнопками.

## Основні компоненти (Виконано у v0.5.0)
1. [x] **AI Entity Extractor & Context Memory (`src/ai/`)**:
   - Підтримка контекстного збереження та об'єднання даних отримувача з доповненнями (наприклад, уточнення опису *"сувенір"*).
   - Повна сумісність з `gpt-5.6-luna`, `gpt-4o-mini`, `o1`, `gemini-3.6-flash`.

2. [x] **Nova Poshta API Client (`src/nova_poshta/`)**:
   - Пошук населених пунктів та поштоматів/відділень (`FindByString`).
   - Створення контрагента та створення ТТН (`InternetDocument/save`).
   - Видалення ТТН/чернеток (`InternetDocument/delete`).
   - Отримання активних посилок (`InternetDocument/getDocumentList`).

3. [x] **Telegram Bot Interface (`src/bot/`)**:
   - Постійна клавіатура бота Reply Keyboard меню в 1 клік (`📦 Активні посилки`, `📝 Мої чернетки (ТТН)`, `⚙️ Налаштування`, `❓ Допомога`).
   - Повна українізація всіх текстів, карток та кнопок.
   - Відстеження контексту сесії `USER_ACTIVE_SESSIONS`.

4. [x] **Персональне збереження даних (`src/storage.py`)**:
   - Локальний менеджер збереження налаштувань користувача та створених чернеток.
