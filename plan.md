# План розробки Telegram-бота "Nova Poshta AI Waybill Generator"

## Опис проекту
Створення Telegram-бота на Python (aiogram 3.x), який за допомогою штучного інтелекту (з гнучким вибором OpenAI-сумісного API, офіційного OpenAI або Gemini) парсить неструктурований текст із реквізитами отримувача (ПІБ, телефон, місто, номер відділення/поштомату, опис, оціночна вартість) без використання регулярних виразів, з підтримкою об'єднання перепощених повідомлень через асинхронний дибаунсинг, редагування чернеток живою мовою, автоматичним скиданням контексту та нижньою клавіатурою з кнопками.

## Основні компоненти (Виконано у v0.9.0)
1. [x] **AI Entity Extractor & Multi-Part Memory (`src/ai/`)**:
   - 100% AI-ориєнтований парсинг без регулярних виразів з робастною валідацією Pydantic для `null` значень.
   - Повна сумісність з `gpt-5.6-luna`, `gpt-4o-mini`, `o1`, `gemini-3.6-flash`.

2. [x] **Nova Poshta API Client (`src/nova_poshta/`)**:
   - Пошук населених пунктів та поштоматів/відділень (`FindByString`).
   - Створення контрагента та створення ТТН (`InternetDocument/save`).
   - Оновлення чернеток ТТН (`InternetDocument/update`).
   - Видалення ТТН/чернеток (`InternetDocument/delete`).
   - Отримання активних посилок (`InternetDocument/getDocumentList`).

3. [x] **Telegram Bot Interface (`src/bot/`)**:
   - Постійна клавіатура бота Reply Keyboard меню в 1 клік (`📦 Активні посилки`, `📝 Мої чернетки (ТТН)`, `⚙️ Налаштування`, `❓ Допомога`).
   - Асинхронний дибаунсер (`USER_MESSAGE_BUFFERS`, `USER_DEBOUNCE_TASKS`) для об'єднання миттєвих перепощених повідомлень у 1 запит.
   - Кнопка `✏️ Редагувати ТТН` з парсингом через AI Extractor.
   - Скидання контексту сесії `clear_user_active_session(user_id)` після створення ТТН чи переходу до меню.

4. [x] **Персональне збереження даних (`src/storage.py`)**:
   - Локальний менеджер збереження налаштувань користувача та створених чернеток.
