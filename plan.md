# План розробки Telegram-бота "Nova Poshta AI Waybill Generator"

## Опис проекту
Створення Telegram-бота на Python (aiogram 3.x), який за допомогою штучного інтелекту (OpenAI-сумісного API / Gemini) парсить неструктурований текст із реквізитами отримувача без регулярних виразів, формує експрес-накладні (ТТН), забезпечує інтелектуальне об'єднання чернеток у реєстри (ScanSheet) на основі природномовних запитів та генерує штрих-коди Code128 для швидкого сканування на відділеннях Нової Пошти.

## Основні компоненти (Виконано у v0.19.2)
1. [x] **AI Entity Extractor & Smart Register Builder (`src/ai/`)**:
   - Повна ізоляція AI-провайдера за Telegram `user_id`.
   - Розпізнавання суми та виплати накладеного платежу (`cod_amount`, `cod_payment_type`).
   - Виявлення підозри на адресну доставку додому (`is_address_delivery`, `street_name`, `building_number`, `flat_number`).
   - **Нове**: Метод `filter_drafts_for_register` — прийом масиву активних чернеток у форматі JSON разом із промптом користувача ("з усіх чернеток", "з накладної 2045...", "створені вчора", "з описом сувенір").
   - Повернення структурованого результату `AIRegisterFilterResult` з точними номерами ТТН для створення реєстру.

2. [x] **Nova Poshta API Client & Barcode Generator (`src/nova_poshta/`, `src/utils/`)**:
   - Пряме завантаження чернеток з кабінету НП через `InternetDocument/getInternetDocumentList`.
   - Генерація високоякісного Code128 штрихкоду реєстру (у форматі `105-79184007`).
   - Формування масиву зворотної доставки `BackwardDeliveryData` при `cod_amount > 0`.
   - Створення реєстру через `create_scan_sheet` з перевіркою коректності та retry-механізмом.

3. [x] **Telegram Bot Interface (`src/bot/`)**:
   - Єдина функція синхронізації невідправлених чернеток `fetch_user_active_drafts`.
   - Повний цикл обробки запитів на створення реєстру: відбір чернеток через AI -> створення в API НП -> надсилання штрих-коду та карток доданих накладних.
   - Меню керування реєстрами з можливістю розформування / видалення.

4. [x] **Персональне збереження даних (`src/storage.py`)**:
   - Індивідуальне збереження налаштувань користувача в `data/user_settings.json` за Telegram `user_id`.
   - Автоматичне очищення відправлених чернеток (`purge_sent_drafts`) та застарілих/відправлених реєстрів (`purge_old_or_sent_scansheets`).
