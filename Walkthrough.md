# Walkthrough (Журнал змін)

## [v0.12.0] - 2026-08-07
- **Реєстри експрес-накладних (ScanSheet) та фільтрація чернеток живою мовою**:
  - Інтегровано API 2.0 Нової Пошти для роботи з реєстрами (`ScanSheet/save`, `ScanSheet/getScanSheetList`, `ScanSheet/deleteScanSheet`).
  - AI навчено аналізувати природні запити користувача для фільтрації чернеток за датою (наприклад, *"за сьогодні"*, *"за вчора"*, *"вчора до обіду/12:00"*), описом вантажу (*"з описом сувенір"*, *"з описом планшет"*) або створювати реєстр з усіх чернеток.
  - Додано команду `/registers` та кнопку постійного меню `📋 Реєстри (ScanSheet)`.
- **Генерація штрих-кодів Code128 у Telegram**:
  - Створено модуль `src/utils/barcode_gen.py` з підтримкою `python-barcode` та `Pillow`.
  - При створенні реєстру або при натисканні кнопки `📱 Показати штрихкод` бот надсилає у Telegram картинку високої роздільної здатності зі штрих-кодом Code128 для швидкого сканування на відділенні Нової Пошти безпосередньо з екрана смартфона.
- **Уточнення адресної кур'єрської доставки додому (`AddressConfirmCallback`)**:
  - При виявленні у тексті назви вулиці, номера будинку/квартири або слів *"додому"*, *"кур'єром"*, *"на адресу"*, AI активує `has_address_suspicion: true`.
  - Бот не робить передчасних припущень, а виводить інлайн-вікно з питанням та двома кнопками: `[ 🚚 Доставка кур'єром додому ]` та `[ 📦 Доставка у відділення / поштомат ]`.
- **Збереження реєстрів**: Додано локальну багатокористувацьку базою даних для реєстрів у `data/user_scansheets.json`.
- **Тестування**: Створено модульний тест `tests/test_scan_sheet.py`. Усі 16 модульних тестів успішно виконані (`16 passed in 2.19s`).
