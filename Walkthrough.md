# Walkthrough (Журнал змін)

## [v0.4.1] - 2026-08-07
- **Виправлено сумісність з новітніми моделями OpenAI (`gpt-5.6-luna`, `o1`, `o3-mini`)**:
  - Прибрано фіксований параметр `temperature=0.1` у виклику `chat.completions.create` в `src/ai/extractor.py`, який спричиняв помилку HTTP 400 (`temperature does not support 0.1`).
- **Повна верифікація з ключами користувача**:
  - Успішно протестовано підключення Telegram бота `@npsender_bot`.
  - Успішно протестовано Nova Poshta API (профіль відправника Рашевський Владіслав Сергійович).
  - Успішно протестовано AI Extractor з підключеним ключем OpenAI та моделлю `gpt-5.6-luna` для розпізнавання реквізитів отримувачів та розмовних відповідей.

## [v0.4.0] - 2026-08-07
- **Керування створеними накладними/чернетками (`/drafts`)**:
  - Реалізовано команду `/drafts` для перегляду карток усіх ТТН/чернеток, створених користувачем у боті.
  - Додано інтерактивну кнопку `🗑 Delete Waybill (Видалити ТТН)` для кожної картки.
  - Реалізовано виклики `InternetDocument/delete` в `src/nova_poshta/client.py` для безпосереднього видалення накладних з бази Нової Пошти за їх внутрішнім GUID `Ref`.
  - Успішно протестовано видалення ТТН у Новій Пошті.
- **Персональне збереження ключів (`/set_np_key`, `/set_ai_key`)**:
  - Користувачі можуть додавати та переключати свої власні API-ключі Нової Пошти та AI через бот у будь-який момент.
  - Створено `src/storage.py` з локальним збереженням `data/user_settings.json` та `data/user_drafts.json`.
- **Тестування**: Додано модульні тести `test_drafts_management` та `test_user_settings_manager`. Усі 9 тестів успішно виконані.
