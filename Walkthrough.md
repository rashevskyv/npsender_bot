# Walkthrough (Журнал змін)

## [v0.9.0] - 2026-08-07
- **Асинхронний дибаунсинг та буферизація перепощених повідомлень (Async Message Debouncer)**:
  - Реалізовано буфер `USER_MESSAGE_BUFFERS` та асинхронний таймер `USER_DEBOUNCE_TASKS` у `src/bot/handlers.py`.
  - При надсиланні/перепощуванні декількох повідомлень поспіль Telegram надсилає апдейти з інтервалом у мілісекунди. Бот призупиняє обробку на 1.0 секунду, скидає проміжні таймери та накопичує всі перепощені повідомлення у єдиний текстовий блок.
  - Потім накопичений текст передається в AI Extractor одним єдиним запитом, що усуває гонку запитів (race conditions), подвійні виклики API та гарантує 100% точність розпізнавання реквізитів з усіх перепощених блоків!
- **Тестування**: Усі 12 модульних тестів виконано успішно (`12 passed in 0.30s`).
