# Walkthrough (Журнал змін)

## [v0.1.3] - 2026-08-07
- **Виправлено роботу з поштоматами**: У методи пошуку відділень `Address/getWarehouses` додано безпосередній фільтр `FindByString` та `WarehouseId` для миттєвого знаходження поштоматів (наприклад, №26584) у великих містах (Київ тощо).
- **Виправлено генерацію ТТН**: До виклику `InternetDocument/save` додано обов'язковий масив місць `OptionsSeat` з об'ємними габаритами вантажу, що усунуло помилку API `OptionsSeat is empty`.
- **Протестовано реальне створення ТТН**: Успішно згенеровано реальну накладну Нової Пошти (№ `20451506103956`) для отримувача в м. Київ (Поштомат №26584) від відправника Рашевського Владіслава з м. Івано-Франківськ (Відділення №8).
- **Оновлено конфігурацію**: Заповнено реальні GUID відправника у файлі `.env`.

## [v0.1.2] - 2026-08-07
- Реалізовано повний базовий функціонал проєкту Nova Poshta AI Waybill Generator:
  - **Конфігурація & Налаштування**: `src/config.py` (Pydantic BaseSettings) з підтримкою 3-х режимів AI провайдерів (`openai_compatible`, `openai`, `gemini`), `.env.example`, `.gitignore`.
  - **AI Entity Extractor**: `src/ai/extractor.py` та `schemas.py` за допомогою AsyncOpenAI SDK для підключення як до офіційних OpenAI/Gemini API, так і до локального `gemini-web2api v1.2.9` (`http://localhost:8081/v1`).
  - **Nova Poshta API Client**: `src/nova_poshta/client.py` та `models.py` з підтримкою пошуку населених пунктів, відділень/поштоматів, створення контрагента та генерації ТТН.
  - **CLI Helper**: `src/cli/fetch_sender_info.py` для швидкого автоматичного вилучення ідентифікаторів відправника.
  - **Telegram Bot (aiogram 3)**: `src/bot/handlers.py`, `keyboards.py`, `main.py` з інтерактивною карткою перевірки та кнопками перемикання платника (Отримувач/Відправник) та типу вантажу перед формуванням ТТН.
  - **Тестування & Документація**: Додано модульні тести в `tests/`, оновлено `README.md` (англійською мовою) та `docs/credentials_guide.md`.
- Усі модульні тести в `tests/` пройшли успішно.
